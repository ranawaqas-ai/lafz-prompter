# Contributing

Bug reports and pull requests are welcome. Please open an [issue](https://github.com/ranawaqas-ai/lafz-prompter/issues) before starting on a larger change, so we can agree on the approach first.

## Before you open a pull request

- Build with `swift build` and run the tests with `swift test`.
- Keep each pull request to one change, with a short description of why it is needed.

## Contributor License Agreement

Lafz Prompter is released under the GNU General Public License version 3 or later. Contributions also need the [Contributor License Agreement](CLA.md), which lets the maintainer offer the project under other terms too, for example a paid edition.

On your first pull request a check asks you to sign by posting this comment:

> I have read the CLA Document and I hereby sign the CLA

You only sign once. The check records your GitHub username and the pull request.
