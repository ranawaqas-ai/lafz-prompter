Privacy Policy

Last updated: November 2026

No data collected

Lafz Prompter does not collect, store, send or process any personal or usage data. There are no analytics, no telemetry and no accounts.

No network requests

The app makes no network requests. Your scripts and settings are stored only in the app's preferences on your Mac.

Microphone

Voice activation needs microphone access. The mic is used only while voice activation is listening, which starts when you press Play. Audio is measured for loudness on your Mac in real time and is never recorded, stored or sent anywhere.

This website

This site is hosted on GitHub Pages and loads fonts from Google Fonts, so those services see your IP address as part of serving the page. The site itself sets no cookies and uses no analytics.

Source code

Lafz Prompter is open source under the MIT License, so you can check all of this in the source code. Questions go to the project's issue tracker.
