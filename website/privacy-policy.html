Privacy Policy

Last updated in November 2026

Data collection

Lafz Prompter does not collect, store, send or process personal data or usage data. The app contains neither analytics nor telemetry, and it does not require an account.

Network access

The app does not make network requests. Your scripts and settings are stored only in the preferences of the app on your Mac.

Microphone

Voice activation needs access to the microphone. The app uses the microphone only while voice activation is listening, which starts after you press Play. Audio is measured for loudness on your Mac in real time and is not recorded, stored or sent anywhere.

This website

This site is hosted on GitHub Pages and loads fonts from Google Fonts, so those services see your IP address as part of serving the page. The site itself does not set cookies or use analytics.

Source code

Lafz Prompter is open source under the MIT License, so that you can verify these statements in the source code. Please send questions to the project's issue tracker.
